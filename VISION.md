# Telegram User CLI

Give people and their agents a small command interface to their own Telegram account.
The first workflow is install, login, read a chat, send exact text, and inspect the result.

Favor JSON output, explicit targets, exact UTF-8 input, local private sessions, and
useful errors over a daemon or a large integration framework. Telethon owns the
Telegram protocol. This project owns the command interface and agent guidance.

This is not a bot platform, bulk outreach service, gateway, or autonomous reply engine.
Success means a clean installation works outside the author's development environment.
